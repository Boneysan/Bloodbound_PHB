# Player's Handbook

Welcome to the **Legacy of Kain: Bloodbound RPG** Player's Handbook — a tabletop roleplaying game set in the gothic, blood-soaked world of Nosgoth.

> *"The Wheel of Fate is ever turning. Every soul cast into its current is destined to return."*

This handbook contains everything you need to create a character, understand the rules, and descend into the ruins of a world where the war between vampires, humans, wraiths, and Hylden never truly ends.

## How to Use This Handbook

**New players** should start with [Chapter 1 — Character Creation](./01-character-creation) for a guided walkthrough of building your first character.

**Rules reference** is in [Chapter 0 — Core Mechanics](./00-core-mechanics), the single source of truth for all fundamental resolution systems.

**Magic users** will want to read [Chapter 5 — Spellcasting & Magic](./05-spellcasting-and-magic) carefully — Nosgoth's magic is powerful, volatile, and always carries a price.
